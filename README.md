# Магістерська робота: платформа адаптивного спорту для ветеранів

**Студент:** Тимошенко Юрій · Master of Science in Computer Science (Software Engineering), Neoversity · індивідуальна робота
**Тип роботи:** інженерний проєкт (MVP)
**План роботи:** [docs/work_plan.md](docs/work_plan.md)

## Тема

Веб-платформа для пошуку партнерів з адаптивного спорту серед ветеранів на основі AI-алгоритму підбору за функціональними можливостями.

**Мета.** Створити MVP веб-платформи, яка допомагає ветеранам і військовослужбовцям із пораненнями (зокрема ампутаціями) знаходити партнерів для спільних тренувань за видом спорту, локацією та рівнем функціональних можливостей.

**Проблема.** В Україні є офлайн-підтримка (хаби на кшталт Veteran Hub) та елітний рівень (збірна, Ігри Нескорених). Масового цифрового інструмента для щоденного пошуку партнера поруч немає.

## Наукова новизна

1. **Багатокритеріальний підбір партнерів (Matching Engine).** Алгоритм поєднує відстань, вид спорту, сумісність за функціональними можливостями й асистивним обладнанням та відповідність інтенсивності тренувань. Замість бінарного фільтра він видає неперервну оцінку сумісності (0–100%) з поясненням внеску кожного критерію. Тому він знаходить прийнятні варіанти навіть у розрідженій вибірці (малі населені пункти). AI-складова — ранжування, що навчається на зворотному зв'язку, і його порівняння з базовим зваженим скорингом.
2. **Демедикалізована таксономія функціональних можливостей (Zero-Stigma Taxonomy).** Профіль описує, *що людина може робити і чим користується* (тип протеза, активне крісло тощо), а не діагноз. Це прибирає потребу зберігати клінічні дані й знижує бар'єр самоідентифікації як «хворого».
3. **Privacy-by-Design для чутливих даних.** Приватний шар (функціональні дані, доступний лише алгоритму підбору) відокремлений від публічного представлення профілю. Точна геолокація не зберігається й не передається: лише огрублена до району (радіус 3–5 км, geo-fuzzing).

## Практична цінність

- **Для ветеранів:** безкоштовний щоденний спосіб знайти партнера для тренувань поруч без розкриття діагнозу чи точної адреси. Це підтримує фізичне відновлення та соціальну реінтеграцію за принципом «рівний — рівному».
- **Для хабів і реабілітаційних центрів:** post-rehab інструмент супроводу ветеранів після завершення клінічної реабілітації.
- **Для спортивних комплексів і тренерів:** канал залучення ветеранської аудиторії та аналітика попиту (джерело монетизації при безкоштовному доступі для ветеранів).
- **Для інженерної спільноти:** відтворюваний референс-проєкт (код, тести, документація) з шаблоном архітектури для застосунків із чутливими даними та відкритим алгоритмом підбору, який можна перевірити на синтетичних профілях.
- **Продукт:** працюючий MVP (FastAPI + PostgreSQL, React + TypeScript), покритий тестами, з розгортанням через Docker Compose та описаним API (OpenAPI).
